# FC01首测视觉现场配置来源

`FC01_VISION_SITE_TEMPLATE.json`是**未标定模板**。null/false/空ID会被配置工具拒绝；不能批量改true后当作校准完成。定高模式不需要填写它，也不依赖相机。

先复制到版本目录以外，例如`$HOME/fc01_site.json`，防止版本切换覆盖现场记录。填写`provenance`的设备、内参、外参、目标模型、采集延迟、安全间距六项来源：实际设备序列/稳定路径、测量日期、校准文件或实验记录。工具记录整份来源文件SHA，不将仓库示例数值认作现场测量。

- 相机设备：使用现场`/dev/v4l/by-id/...`实际图像节点，或已核对的`/dev/videoN`。本程序使用USB/V4L2图像，串口MicoVIO里程计字节不等同于目标图像源；若设备只输出里程计，则不能用它冒充目标识别相机。
- 内参：图像宽高、fx/fy/cx/cy为校准后的像素单位。本实现消费矫正图像/零畸变适用模型；需确认图像与K对应。帧率填实际配置支持值，不能引用上游笔记本120fps结论。
- 外参：`camera_to_body_wxyz`是目标FRD相机分量转机体FRD的Hamilton单位四元数；`camera_pos_x/y/z`是相机中心相对机体原点的**FLU**杆臂，单位米（前/左/上）。两处ID引用同一次安装记录。勿把FRD平移直接填入FLU。
- 目标：明确circle或rect；直径/宽高以现场目标实测米值填写。circle模板不代表任意形状有效。rect还需target_width_m/target_height_m。
- 延迟：`capture_latency_bound_s`填写实际采集时延的保守上界，单位秒；不是检测耗时。未测不可确认。源帧时间/序号和重复检查继续生效。
- 安全间距：`standoff_m`为现场确认的目标保持距离，米。源记录应说明目标/机体尺寸与试验条件。工具不把默认1m认作你的安全间距。

首测选择`horizontal_navigation_mode=hold`；到高后先保持，再由连续有效新帧进入track。若使用waypoint，还需显式当前PX4局部原点与坐标对齐记录、有界XY航点。工具不能由上次启动的原点推定本次航点有效。

水平候选上界速度0.5m/s、半径2m、偏航0.35rad/s；配置可收紧，不扩大原生限制。原生高度固定1.5m；视觉航点z/视觉垂速无垂向权限。

配置在落地、拆桨、飞控断电且服务已停时执行，工具只改deployment并完整备份，不触发解锁/起飞。相机可暂时不插；启动后应明确报告缺相机/缺目标并待机，而不是伪造视觉就绪。实际命令见本次安装交付说明。
